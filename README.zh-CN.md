# NNotepad

[English](README.md) · [简体中文](README.zh-CN.md)

**Simple is enough.** 简单，就够了。

一个轻量的网页版记事本，支持纯文本和 Markdown。可以写笔记、粘贴 AI 回答，也能直接修改排版后的内容，无需安装或注册账号。

**打开 `index.html` 就能使用。** 不需要构建或服务器。

## 核心功能

| 功能 | 用法 |
| --- | --- |
| TXT 与 Markdown | 每篇笔记独立选择格式，切换保留原文。 |
| 可编辑的预览 | 编辑原文、左右分屏，或直接修改排版结果。 |
| 静默自动保存 | 输入时保存到浏览器，只有异常才显示提示。 |
| 多笔记管理 | 左侧新建笔记，搜索标题和正文。 |
| 导入与导出 | 左侧打开文件；右键笔记可导出或删除。 |
| 备份与恢复 | 下载全部笔记的 JSON 备份，之后可恢复。 |
| 简洁界面 | 浅色与深紫色主题、字号调整、侧栏收起。 |

Markdown 支持标题、粗体、斜体、列表、任务列表、引用、表格、链接和代码块。组件均已保存在项目中，编辑和渲染可离线运行。

## 开始使用

1. 下载仓库 ZIP 并解压，或者克隆仓库：

   ```sh
   git clone https://github.com/Ahorns/NNotepad.git
   ```

2. 用现代浏览器打开 **`index.html`**，保留旁边的 `vendor/` 文件夹。
3. 新建笔记。粘贴 Markdown 后，选择 **MD Markdown** 即可看到排版。
4. 选择 **分屏** 对照原文与结果，或选择 **预览** 直接编辑排版后的内容。

导入 `.md` 或 `.markdown` 文件自动进入 MD 模式。MD 模式导出 `.md`，TXT 模式导出 `.txt`。

## 自动选择语言

界面根据浏览器首选语言选择：**中文显示简体中文，其他语言显示英文**。没有语言切换按钮，笔记内容不会被翻译。

浏览器通常沿用操作系统语言，但网页无法直接读取 Windows 显示语言。如果单独设置过浏览器语言，以浏览器首选语言为准。

## 笔记保存在哪里

笔记存在当前浏览器的 **localStorage** 中，不会自动写入项目文件夹，也不会上传到远程账号。上传源码不会上传你的笔记。

- 下次使用同一个浏览器和相同文件路径或网站地址，可继续查看原笔记。
- 清理浏览器数据、无痕模式、移动文件或更换浏览器，可能导致原笔记无法读取。
- **备份全部**下载 JSON 文件；**恢复备份会替换当前全部笔记**，恢复前请先备份。
- 从原版迁移到新文件夹或另一台电脑时，先在旧页面备份，再在新页面恢复。
- 避免多个窗口同时编辑。检测到其他窗口更新时，先导出未保存的修改，再刷新。

编辑可离线运行。笔记引用的网络图片和外部链接可能访问网络。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl / ⌘ + S | 导出当前笔记 |
| Ctrl + Alt + N | 新建笔记 |
| Ctrl + B / Ctrl + I | 排版编辑区粗体 / 斜体 |
| Ctrl / ⌘ + 点击链接 | 打开链接 |
| Esc | 关闭右键菜单或手机侧栏 |

## 文件结构

```text
index.html          页面结构与英文默认文案
style.css           布局、主题与响应式样式
app.js              笔记、保存、Markdown 编辑与菜单
i18n.js             自动选择中英文界面
vendor/             离线组件与各自的许可证
README.md           英文说明
README.zh-CN.md      中文说明
THIRD_PARTY.md      组件版本与来源
```

这是一个纯静态网页项目，无需安装依赖或编译。可直接编辑源码，或使用静态文件服务托管；笔记仍分别保存在每位使用者自己的浏览器中。

## 当前支持范围

- 排版区编辑后，Markdown 空白和符号会统一整理；仅切换视图不会改写原文。
- 任务列表复选框仅用于展示。
- 暂不支持 LaTeX 公式、Mermaid 图表和代码语法高亮。
- 导入文本按 UTF-8 解码。
- 不提供跨设备或跨浏览器同步。

第三方组件说明见 [THIRD_PARTY.md](THIRD_PARTY.md)，原始许可证文件保存在 `vendor/` 中。
